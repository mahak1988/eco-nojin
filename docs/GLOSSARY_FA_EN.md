# Glossary · واژه‌نامه تخصصی (fa / en)

UI languages: **Persian (fa)** and **English (en)**. Code identifiers stay English.

| English (code / API) | فارسی | Notes |
|----------------------|--------|-------|
| NDVI | شاخص پوشش گیاهی تفاضلی نرمال‌شده | (NIR−Red)/(NIR+Red) |
| EVI | شاخص بهبودیافته پوشش گیاهی | |
| LST | دمای سطح زمین | Land Surface Temperature |
| DEM | مدل رقومی ارتفاع | Digital Elevation Model |
| SAR | رادار روزنه مصنوعی | Synthetic Aperture Radar |
| soil moisture | رطوبت خاک | m³/m³ or % |
| root zone | ناحیه ریشه | typically 0–100 cm |
| ET0 | تبخیرتعرق مرجع | reference evapotranspiration |
| ETc | تبخیرتعرق گیاهی | ET0 × Kc |
| Kc | ضریب گیاهی | crop coefficient |
| AquaCrop | مدل آب–محصول فائو | crop-water productivity |
| RothC | مدل کربن آلی خاک | Rothamsted Carbon |
| SOC | کربن آلی خاک | Soil Organic Carbon |
| SPI / SPEI | شاخص بارش استاندارد / با ET | drought indices |
| SMAP | مأموریت رطوبت خاک ناسا | |
| ASCAT | پراکنش‌سنج رطوبت خاک | Metop |
| GRACE-FO | ناهنجاری ذخیره آب خشکی | groundwater proxy |
| GIBS | سرویس مرور تصویر ناسا | no API key for tiles |
| Open-Meteo | هواشناسی باز | no key |
| OpenTopoData | ارتفاع‌سنجی باز | SRTM etc. |
| Celery | صف کارهای پس‌زمینه | Redis broker |
| WebSocket | کانال بلادرنگ | `/ws/monitoring` |
| alert rule | قانون هشدار | threshold on sensor |
| change detection | تشخیص تغییر | NDVI delta |
| timeseries | سری زمانی | |
| phenology | فنولوژی | green-up / senescence |
| biomass | زیست‌توده | |
| land cover | پوشش اراضی | |
| irrigation | آبیاری | |
| pest habitat | زیستگاه آفت | climate suitability |
| MRV | پایش–گزارش–راستی‌آزمایی | carbon |
| fallback provider | ارائه‌دهنده پشتیبان | chain pattern |
| soft delete | حذف نرم | `is_deleted` |
| HttpOnly cookie | کوکی فقط‌HTTP | XSS-resistant token store |
