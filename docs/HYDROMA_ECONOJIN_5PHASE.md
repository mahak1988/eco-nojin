# هیدروما نوژین × اکو نوژین — نقشه ۵ فاز

منبع: طرح توجیهی فنی کشت‌وصنعت دشت امید نارون / مرکز رشد یاسوج.

## دو هسته

| هسته | نقش | در پلتفرم |
|------|-----|----------|
| **هیدروما نوژین** | ۱۲ بسته فنی-مهندسی (HP) احیای آب، خاک، معیشت | صفحات آبخیز، مرتع، کود زیستی، پایلوت‌ها |
| **اکو نوژین** | پلتفرم پایش/دانش‌یار/تصمیم‌یار/MRV/فروشگاه/کتابخانه | همین مخزن (apps/web + API) |

## چهار اصل مهندسی هیدروما

1. مدیریت رواناب در مبدأ  
2. افزایش زمان ماند هیدرولیکی  
3. بستن حلقه مواد آلی  
4. تلفیق دانش بومی + مهندسی مدرن  

## شش مدل شبیه‌سازی (زنجیره اعتبارسنجی)

SWAT+ · RUSLE · RothC · AquaCrop · WEAP · HEC-RAS  
هدف: خطای پیش‌بینی < ۱۰٪ پس از کالیبراسیون میدانی.

## چهار پایلوت اقلیمی

1. دیشموک — کوهستان خشک (کهگیلویه و بویراحمد)  
2. بهبهان — نیمه‌خشک شور (خوزستان)  
3. رودبار / تالش — جنگل مرطوب هیرکانی (گیلان)  
4. یاسوج / بویراحمد علیا — کوهستان برف‌تأمین  

## تقسیم سود (مدل حکمرانی)

## فاز ۲ — دانش‌یار و تصمیم‌یار (۲–۳ هفته)

- دانش‌یار: RAG روی SOPهای ۱۲ بسته HP + FFS + کتابخانه
- تصمیم‌یار: توصیه بر اساس NDVI + رطوبت + سناریوی AquaCrop/RothC
- اتصال به `/api/v1/ai` با provider رایگان/محلی
- تریگرهای ریسک SPI-3 و VHI (هشدار پیش‌دستانه)

## فاز ۳ — آبخیزداری، مرتع، کود زیستی (۳–۴ هفته)

- کاتالوگ ۱۲ بسته HP (کانال مارپیچ، چاهک نفوذ، بندک‌های سنگ‌آهکی، …)
- ماژول کود زیستی: بیوچار، ورمی‌کمپوست، کنسرسیوم میکروبی (IMO+AMF+PGPR+Trichoderma)
- مرتع: مدیریت چرا، SWC–AgMAR، گیاهان دارویی
- APIهای شبیه‌ساز RUSLE2 / WEAP-simple / CBA (موجود به‌صورت proxy)

## فاز ۴ — MRV، مدارس مزرعه‌ای، حکمرانی (۳–۴ هفته)

- MRV سه‌سطحی منطبق GSOC-MRV فائو
- FFS سه‌سطح + KoboToolbox آفلاین
- سند توافق منظر (قالب حقوقی)
- شفافیت تقسیم سود (دفتر ثبت — قرارداد هوشمند اختیاری)

## فاز ۵ — مقیاس‌پذیری و استقرار رایگان (۲–۳ هفته)

- پایلوت‌های ۴۰۰ هکتاری در UI با داده واقعی API
- استقرار FREE_STACK (Vercel + Render/Fly + Neon)
- گزارش‌های CSV/PDF خدمات اکوسیستمی
- کالیبراسیون مدل‌ها با داده محلی ایران
